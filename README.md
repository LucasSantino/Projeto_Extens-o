# Projeto_Extensão
Repositorio para o projeto de extensão. Landpage para ONG - Arco Iris

🌈 ONG Arco-Íris – Projeto de Extensão Universitária

Deploy do projeto:
👉 https://projeto-extens-o-one.vercel.app/

Este projeto consiste na criação de uma landing page institucional moderna, responsiva e acessível para a ONG Arco-Íris, uma organização dedicada ao atendimento de crianças, jovens e mulheres em situação de vulnerabilidade social no município de Monte Mor – SP.

A aplicação foi desenvolvida como um Projeto de Extensão Universitária pelo aluno Lucas Santino da Silva, durante o último semestre do curso Tecnólogo em Análise e Desenvolvimento de Sistemas da Escola e Faculdade de Tecnologia SENAI Roberto Mange.

📌 📖 Contexto do Projeto

A ONG Arco-Íris desenvolve atividades sociais, culturais e educacionais voltadas à comunidade do bairro Parque Residencial São Clemente. No entanto, a instituição não possuía um site moderno capaz de apresentar sua história, ações, campanhas e formas de contato.

O objetivo do projeto foi criar uma presença digital eficiente, com foco em:

Fortalecer a comunicação com a comunidade

Facilitar o acesso às informações da ONG

Apresentar eventos, atividades e campanhas

Apoiar iniciativas de arrecadação através de maior visibilidade

Criar uma ferramenta institucional confiável e responsiva

🎯 Objetivos do Projeto

Abaixo estão listados os principais objetivos alcançados:
| Objetivo                                             | Descrição                                                                    |
| ---------------------------------------------------- | ---------------------------------------------------------------------------- |
| **Criação de uma landing page moderna**              | Interface visual responsiva, intuitiva e alinhada à identidade visual da ONG |
| **Fortalecimento institucional**                     | Apresentar missão, valores, atividades e fotos da ONG                        |
| **Otimização do alcance digital**                    | Fornecer um local oficial para acessar informações da ONG                    |
| **Implementação de galeria e seções dinâmicas**      | Exibição organizada das atividades e ações realizadas                        |
| **Integração visual responsiva**                     | Experiência fluida em dispositivos móveis, tablets e desktops                |
| **Entrega profissional para extensão universitária** | Projeto entregue como requisito acadêmico e contribuição social              |

| **JavaScript (ESNext)**   | Funcionalidades da interface                     |
| **Vercel**                | Deploy e hospedagem da aplicação                 |
| **Google Maps Embed API** | Exibição do mapa com localização da ONG          |
| **Figma (Design)**        | Prototipação e estrutura visual                  |
| **Git & GitHub**          | Controle de versão e colaboração                 |

🚀 Funcionalidades Implementadas
| Funcionalidade                             | Descrição                                                   |
| ------------------------------------------ | ----------------------------------------------------------- |
| **Header dinâmico**                        | Altera aparência ao rolar a página e possui navegação suave |
| **Hero com CTA**                           | Botão para navegação direta e destaque institucional        |
| **Seção "Sobre" animada**                  | Imagens sobrepostas com animações e layout responsivo       |
| **Galeria com modal fullscreen**           | Ao clicar, a imagem abre em tela cheia com fundo escurecido |
| **Paginação automática da galeria**        | Exibe múltiplas imagens em páginas distintas                |
| **Mapa integrado**                         | Localização da ONG via Google Maps Embed                    |
| **Rodapé institucional com redes sociais** | Links úteis, identidade visual e logo integrada             |
| **Layout totalmente responsivo**           | Adaptado para mobile, tablets e desktop                     |
| **Animações e microinterações**            | Efeitos suaves de transição e hover                         |
| **Design mobile-first**                    | Construção orientada à melhor experiência no celular        |
