# Projeto_Extensão
Repositorio para o projeto de extensão. Landpage para ONG - Arco Iris

🌈 ONG Arco-Íris – Projeto de Extensão Universitária
Landing Page Responsiva desenvolvida por Lucas Santino da Silva

🔗 Deploy do projeto: https://projeto-extens-o-one.vercel.app/

📌 📖 Sobre o Projeto

Este projeto consiste no desenvolvimento de uma landing page institucional para a ONG Arco-Íris, uma organização não governamental localizada em Monte Mor – SP, que atua com crianças, jovens e mulheres em situação de vulnerabilidade social.

A aplicação foi construída como parte de um projeto de extensão universitária, realizada pelo aluno Lucas Santino da Silva, durante o último semestre do curso de Tecnologia em Análise e Desenvolvimento de Sistemas, na Escola e Faculdade de Tecnologia SENAI Roberto Mange.

O foco principal do projeto foi:

Modernizar a presença digital da ONG;

Oferecer uma interface acessível, limpa e profissional;

Facilitar o contato, a apresentação dos projetos e a divulgação de ações sociais.

🎯 Objetivos do Projeto
✔️ Criar uma landing page moderna, responsiva e acessível

Utilizando boas práticas de UI/UX, design limpo e experiência intuitiva.

✔️ Fortalecer a visibilidade da ONG Arco-Íris

Permitindo que visitantes compreendam rapidamente a missão, atividades e impacto da instituição.

✔️ Facilitar o contato e visitas

Com seção de endereço, redes sociais e integração com Google Maps.

✔️ Criar uma galeria funcional

Com paginação e modal fullscreen ao clicar nas imagens.

✔️ Aplicar tecnologias estudadas durante o curso

Como Vue 3, TypeScript e práticas modernas de desenvolvimento front-end.
